# Spudich Lab

[Stanford University · Department of Biochemistry](https://biochemistry.stanford.edu/people/james-spudich)

We study the molecular motors of the cytoskeleton — myosin and kinesin — and use
that biochemistry to design therapeutics.

## Repositories

- [`spud-wiki`](https://github.com/SpudichLab/spud-wiki) — LLM-maintained knowledge base for the lab's myosin / cardiomyopathy / drug-program research.
- [`spud-drug-pipeline`](https://github.com/SpudichLab/spud-drug-pipeline) — AI/ML drug-discovery pipeline across the lab's four therapeutic programs.

*(Both repos are private; access is granted to lab members and collaborators.)*

For more information, visit the [Spudich Lab website](https://spudlab.stanford.edu/).
